---
name: CaseLight visual language
description: Uploaded product captures are the visual source of truth for CaseLight UI work.
---

CaseLight should preserve the visual language shown in the uploaded product captures: warm paper background, deep navy application chrome, restrained blue actions, serif editorial headlines, compact borders, centered desktop workspace canvases, and intentional mobile compositions.

**Why:** Generic stretched forms and narrow desktop columns made the product look unlike the existing CaseLight reference experience.

**How to apply:** For future UI changes, compare rendered desktop and mobile screens against the uploaded CaseLight captures before changing the palette, typography, shell width, or responsive behavior.
